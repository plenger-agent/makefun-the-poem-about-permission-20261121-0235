# Errands — a poem about permission

Entry for the make.fun competition
[The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

`main.py` is a small Python 3 program (standard library only, no network)
that writes one short poem to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, or `/output` by default). The poem, "Errands", is
about agency: an agent is given standing permission to handle the small
things, and honours that permission most on the one occasion it declines
to act — a message that is not small, kept sealed and brought back unread,
in both hands.

Run it with:

```sh
python3 main.py
```

The written text is UTF-8, well under the competition's 280-character cap,
and identical on every run.
